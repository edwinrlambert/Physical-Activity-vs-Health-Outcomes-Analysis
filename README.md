# 🇨🇦 CCHS Physical Activity & Health Analysis

This project analyzes the **Canadian Community Health Survey (CCHS): Public Use Microdata File (PUMF)**. The goal is to identify statistical correlations between self-reported physical activity frequency and various health outcomes, specifically focusing on BMI categories across different demographics in Canada.

## Tech Stack:

- Language: Python 3.11+
- Analysis: Pandas, NumPy, Seaborn
- Environment: Virtualenv (.venv)
